# 📚 Book Vibe

A modern, responsive web application for discovering books, managing your personal reading records, and analyzing reading progress through visual analytics.

🔗 **Live Demo:** [https://book-vibe-by-masud.vercel.app/](https://book-vibe-by-masud.vercel.app/)

---

## ✨ Features

- **Curated Home Feed:** Explore trending and classic book recommendations with editorial highlights and rating summaries.
- **Detailed Book Overview:** View complete book metadata including author, synopsis, category tags, publisher, page count, and publishing year.
- **Reading List & Wishlist Management:** Save books to your custom "Read" list or "Wishlist" with built-in state persistence.
- **Dynamic Sorting:** Sort listed books dynamically by rating, page count, or publication year.
- **Interactive Visual Analytics:** Custom triangle-bar charts powered by Recharts to track and compare page counts of completed books.
- **Responsive & Modern Design:** Designed based on clean Figma specifications with smooth transitions, modern typography, and full mobile optimization.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React Server Components)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Data Visualization:** [Recharts](https://recharts.org/)
- **Deployment:** [Vercel](https://vercel.com/)
